# Rivardo — Portfolio

Personal portfolio site: accounting + AI-agent automation for finance, crypto & Web3 market monitoring.

**Live site:** https://rivardoad9-source.github.io/rivardo-portfolio/

## Isi repo

| File | Keterangan |
|---|---|
| `index.html` | Situs portfolio, satu file statis (tanpa build step, tanpa tracker, tanpa dependency). |

Isi halaman: About, Projects (AI & automation), Experience (PT Sinar Sosro, Prudential), Skills, Education.

## Cara update

1. Edit `index.html`
2. commit + push ke `main`
3. GitHub Pages auto-deploy dari branch `main`, folder root

Tidak ada toolchain yang dibutuhkan — HTML + CSS inline saja.
